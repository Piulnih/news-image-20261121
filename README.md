Sum up 21 November 2026's world news in one image: a program that draws the day's front page — the double-tap strike on Kryvyi Rih, COP31 running into overtime in Antalya, the capture of "El Chapo Isidro" in Mexico, Iran's strikes on US bases in Bahrain, the EU's record €7.9bn aid to Ukraine, Gaza, the M6.7 Peru quake, and the market slide — as one 1024×1024 PNG, drawn from scratch with the Python standard library only. No network, no fonts, no images read in: a hand-written 5×7 bitmap font, a small raster canvas, and a hand-written PNG encoder, so two runs write identical bytes.

## Run it
